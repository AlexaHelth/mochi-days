# もちと、まいにち

**アプリを開く: https://alexahelth.github.io/mochi-days/** （ログイン不要。記録はその端末のブラウザに保存）

日本語の記録Webアプリ。写真入力なし。体重（任意）、ウォーキング時間（任意・整数分）、気分、毎日3つの小さな習慣、日付ごとの自由メモを記録できます。最初に犬・猫・ペンギンから相棒を選び、名前をつけて始めます。相棒は8つの基本表情で反応し、取り組みに応じて4つのお部屋と32種類の衣装が解放されます。各衣装には通常・よろこびの2姿があり、3種すべてで着替えられます。全解放後は、3匹それぞれの特別な姿4種類に会えます。

## 「もちとの時間」を4つのタブに（2026-10-03）

「ふれあう」で直接なでるもちの背景を透過し、お部屋の色や足元のマットが見えるようにしました。3匹の基本表情・すべての衣装・特別な姿に対応する専用WebPを使います。[対応と確認結果](docs/transparent-interaction-pet-2026-10-03.md)。

「ふれあう」のもちは中央で大きく表示し、名前は「もちのお部屋」の右に置きます。画像の右側の吹き出しと案内文は外しました。画面の高さに合わせて画像を調整し、触れ合いボタンと4つのタブが見える配置です。[表示と確認結果](docs/centered-interaction-pet-2026-10-03.md)。

「ふれあう」のお部屋の下に、ふりかえりと同じ見た目の「おさんぽ／休む・遊ぶ／模様がえ／贈りもの」を並べました。足あと・月・家・包みのアイコンと短い名前で選び、タブの下にその内容だけを表示します。スクロール中もタブが上に残り、届いた贈りものには数の目印が付きます。「もちのこと・思い出」「もちとお話する」の入口と、別の思い出の折りたたみは非表示です。

模様がえの選択と遊びの途中経過は4つのタブを行き来しても保たれます。別のタブに移ると休憩の呼吸と音は止まり、贈りものを飾るとお部屋のプレビューにも反映されます。保存済みの記録・思い出・贈りものは保持します。[仕様と確認結果](docs/four-companion-tabs-2026-10-03.md)。

## 短く見渡せるふりかえり・ごほうび（2026-10-03）

ふりかえりは「今週／体重／歩いた分／メモ／記録」を切り替えて見る形にしました。メモは3件、記録は5日ずつ表示し、長いメモは全文を開けます。ごほうびは「おめかし／お部屋／特別なもち」に分け、衣装は4つずつ表示します。種類・解放済み・3匹のイラストから選べ、衣装の詳細を開いて試着や着替えができます。

もちの配信用画像19枚をWebPにし、合計33.8MBから2.0MBへ約94％軽量化しました。PNG原本、画像の寸法、衣装の表示範囲は保持し、開いた項目とページの画像だけを読み込みます。[仕様と確認結果](docs/compact-collections-and-images-2026-10-03.md)。

## 気分の保存と、用途ごとの画面（2026-10-03）

気分の選択は、選んだ顔の背景とチェックで示します。未選択では保存ボタンを無効にし、画面を開いたときのフォーカスを選択済みの枠と区別しました。保存した気分は「きょうの記録」に表示され、同じ日の体重・ウォーキング・習慣・メモを保持します。

おさんぽは景色と物語、ひと休みはもちの動きと遊び、模様がえは部屋のプレビューと見た目の選択に整理しました。贈りものは包みをひらくと絵入りの宝もの棚に加わり、お部屋に1つ飾れます。当初6つの専用画面だった入口は、上記の4つのタブに整理しました。[専用画面を追加した際の仕様と確認結果](docs/focused-companion-and-mood-2026-10-03.md)。

## 体重・ウォーキングの簡単入力（2026-10-03）

体重・ウォーキングの専用入力画面から説明文を減らし、保存ボタンをスクロール領域の外に配置しました。画面が小さくても保存ボタンが見えます。体重の前回との差は大きな文字と背景色で表示します。ウォーキングは、その日が未記録なら前回の分数から選べます。同じ日の保存済みの値や変更中の下書きは引き継ぎます。[確認結果](docs/compact-record-input-2026-10-03.md)。

## 毎日の小さな習慣・わかりやすい「ふれあう」（2026-10-03）

「小さな習慣」は、からだ・休息・食事・気持ち・暮らしなど12分野、180案から毎日3つを選びます。同じ日に開き直しても内容は変わらず、名称とチェック状態を日付ごとに保存します。更新前にチェック済みの習慣と過去の記録は以前の名前を引き継ぎ、次の新しい日から毎日の3案が届きます。

「もち」タブを「ふれあう」に変更しました。もちのお部屋をコンパクトにし、スマホで下の入口に気づける配置にしました。「もちとの時間」は現在4つのタブから選びます。「きょうの過ごし方」と「もちと過ごすペース」の設定は非表示です。[保存仕様と確認結果](docs/daily-habits-and-interaction-2026-10-03.md)。Sites版を別途更新する場合は `drizzle/0005_daily_habit_names.sql` の適用が必要です。

## 記録しやすい「きょう」（2026-10-02）

「きょう」は小さなもちと、気分・体重・ウォーキング・メモの記録一覧、習慣のチェックだけを中心にしました。項目を押すと、その項目だけの入力が開きます。目標はもちの上の1行から変更でき、休む日は記録欄を閉じて、いつでも再開できます。

メニューは「きょう／ふりかえり／ふれあう／ごほうび」の4つです。触れ合いの道具、お話、遊び、模様がえは「ふれあう」へ、今週のあしあとは「ふりかえり」へ移しました。[画面構成と確認結果](docs/focused-today-2026-10-02.md)。

## 触れるとほっとする・疲れた日にも戻れる（2026-10-02）

指でなでる・ぎゅっとする・ブラシ・おやつ・おもちゃで、もちと触れ合えます。呼吸や種別ごとの身ぶり、お出迎え、入力中の小さなもち、「もちと、ひと休み」の専用画面を追加しました。毎日のお世話のノルマはありません。

「今日は軽め」「今日は休む」「今日は提案をお休み」「今日はここまで」を日ごとに保存できます。会えた日は健康記録とは別に残り、休む日もやさしいカレンダーに表示します。週のペースと小さな目標も選べます。前の記録・習慣の設定・おほしさまを保ちます。[20項目の対応と確認結果](docs/care-and-comfort-2026-10-02.md)。Pages版はそのまま利用でき、Sites版の更新時には `drizzle/0003_youthful_squirrel_girl.sql` の適用が必要です。

## もちと暮らす、やさしい時間（2026-10-02）

「もちとの時間」から、3匹それぞれのプロフィールと思い出、短いお話、記録で進むおさんぽ物語、6つの小さな休憩・遊び、模様替え、贈りものを楽しめます。性格・呼び名・言葉の温度・好きな音を選べます。休んでも、なかよしや育った鉢は減りません。音・声・振動は任意で、最初は無効です。

メモだけの手紙、途中までできた習慣、気分の言葉、日のタグ、短いタイマー、書きかけの復元を追加しました。ごほうびは試着でき、解放した日ときっかけが残ります。季節の小箱に受取期限はありません。[③〜⑨・70案の対応と保存仕様](docs/companion-life-2026-10-02.md)。Pages版はそのまま利用でき、Sites版を別途更新する場合は `drizzle/0004_rich_hannibal_king.sql` の適用が必要です。

## 2つの公開方法

| | GitHub Pages版 | Sites版 |
| --- | --- | --- |
| URL | https://alexahelth.github.io/mochi-days/ | Sitesの非公開URL |
| ログイン | 不要 | ChatGPTログインとSitesの招待 |
| 記録の保存先 | その端末のブラウザ（localStorage） | サーバー（Cloudflare D1）。端末をまたいで同じ記録 |
| 更新 | `main` へのpushで自動公開 | Sitesでビルド・デプロイ |

画面と、おほしさま・お部屋・衣装のルールは共通です（入力と解放のルールは `lib/state-rules.ts`）。

## GitHub Pages版の記録

- 記録はその端末のブラウザの中（キー `mochi-days:v1`）だけに保存し、サーバーへは送信しません。別の端末・別のブラウザとは共有されません。
- iPhoneでは、Safariで開いたときとホーム画面から開いたときで保存場所が別々です。ホーム画面に追加してから使い始めてください。アプリ内の「ホーム画面への追加・使い方」にも手順があります。
- ブラウザの履歴・Webサイトデータの消去や、ホーム画面のアプリの削除で記録も消えることがあります。設定の「自分の記録を書き出す」でJSONの控えを保存できます。書き出したファイルから戻す機能はまだありません。
- アプリを開くときは通信が必要です。開いたあとは通信が切れても記録できます。
- `alexahelth.github.io` のほかのGitHub Pagesサイトとは同じオリジンになるため、保存キーにアプリ名を付けています。

## デプロイの更新方法（GitHub Pages版）

1. `main` ブランチにpushします（GitHub上での編集やプルリクエストのマージも同じです）。
2. GitHub Actionsの「GitHub Pages」ワークフロー（`.github/workflows/pages.yml`）が、テスト → ビルド → 公開を自動で行います。進み具合はリポジトリの「Actions」タブで確認できます。数分で https://alexahelth.github.io/mochi-days/ が新しい版になります。
3. やり直すときは Actions →「GitHub Pages」→「Run workflow」。テストかビルドが失敗したときは公開されず、前の版のままです。

リポジトリの Settings → Pages → Build and deployment の Source は「GitHub Actions」にしてあります。「Deploy from a branch」に戻すと、アプリではなくこのREADMEが表示されます。ホーム画面に追加したアプリは、いったん閉じて開き直すと新しい版になります。

公開前に手元で確かめるとき:

```sh
corepack pnpm install
corepack pnpm run build:pages
corepack pnpm run preview:pages
```

`http://localhost:4173/mochi-days/` で公開時と同じ構成を確認できます。

## もちを姉妹アプリで共有

素材の原本とアプリ非依存の表示ロジックは [packages/mochi-assets](packages/mochi-assets/README.md) に分離しました。犬・猫・ペンギン、表情、衣装を「もちと、おでかけ」などにも持ち出せます。別の非公開リポジトリへの分割手順も同梱しています。現段階では同じリポジトリ内の独立パッケージです。

ビルド時に素材を `public/pets` にコピーします。`node packages/mochi-assets/copy-assets.mjs public --check` で原本との一致を確認します。公開フォルダの画像を直接編集せず、パッケージの原本とmanifestを更新してください。ユーザーデータや衣装解放の条件は各アプリで管理し、共通素材には含めません。

## Sites版の認証と共有
Sitesの非公開アクセス制御とChatGPTログインを使用します。新規登録用フォームや独自パスワードはありません。現時点ではサイト所有者のみ。利用者のアカウントメールを確認後、Sitesの許可リストで招待します。一般公開に変更しないでください。
全APIでサーバー由来のユーザーIDを確認し、D1クエリをユーザーIDで絞ります。更新は同一オリジンのJSONリクエストに限定し、キャッシュは禁止しています。

## 保存
Sites版はD1のentries、profiles、stars、GitHub Pages版は端末のlocalStorageに保存します。日付は日本時間。星は1日につき体重・気分・3つの習慣の各1回、最大5個です。同日の編集やチェックし直しで重複しません。チェックを外しても既に獲得した星は失いません。習慣は日ごとの3枠で、表示した名前を記録に保存します。候補の表示だけでは健康記録や星を増やしません。

## 開発・検証
Sites版はSitesのビルドとホスティング手順に従います。GitHub Pages版は `vite.pages.config.ts` と `github-pages/` から静的ファイルを `dist-pages/` に書き出します。Drizzleのマイグレーションはdrizzle/に保存済み。認証・所有者分離・入力検証・星の重複防止は `node tests/auth-storage.cjs` で実際のAPIハンドラーをSQLiteのテスト環境に対して検証します。GitHub Pages版の保存処理は `node tests/device-store.cjs` で検証します。`node node_modules/typescript/bin/tsc --noEmit` で型検証します。

## 相棒・衣装
- 既存アカウントは犬・衣装なしを引き継ぎます。記録・おほしさまは保持されます。
- 初回だけ相棒選択を表示。設定で種類・名前をあとから変更できます。
- 最初の8衣装は累計のおほしさま5 / 12 / 20 / 30 / 40 / 55 / 70 / 90個で解放。新しい24衣装は105〜450個で順に解放します。全衣装・全お部屋が解放される450個で、ほしぞらの特別なもちに会えます。おほしさまは消費しません。解放判定は保存時にも検証します（Sites版はサーバー、GitHub Pages版は端末内の保存処理）。
- 記録後はばんざい、なでるとうっとり、元気な気分ならウインク、習慣達成で照れ顔、夜は睡眠、おつかれなら休憩。お休みの日を責める演出はありません。
- 衣装着用時は通常・よろこびの2差分を使い、衣装を保ったまま反応します。ごほうびの表情アルバムを削除し、一覧では選んだ1匹、詳細では3匹のイラストを見比べられます。新しい衣装・特別なもちを156姿追加し、素材は全228姿です。
- ふりかえりは「今週できたこと→体重→ウォーキング時間→メモ→記録」の順番。グラフ・メモ・記録は直近30日を表示します。古い記録も保存・書き出しには残ります。詳しくは [更新内容と画像・生成プロンプト](docs/rewards-and-reflection-2026-10-01.md)。
- 元の犬4ポーズとPNG原本は保持し、アプリの表示には同じ寸法の軽量WebPを使用。原本は `packages/mochi-assets/assets/`、軽量版は `packages/mochi-assets/web/`、配信用コピーは `public/pets/`。画像はすべて同梱済みで、アプリ利用時に画像生成APIは呼びません。
- 衣装は実際のイラストの境目に合わせた表示範囲を使い、隣のイラストの混入と帽子・足の見切れを防ぎます。[表示範囲の修正](docs/reward-framing-2026-10-02.md)。
- 差分仕様・素材一覧は [docs/pet-design.md](docs/pet-design.md)。

Sites版への反映には、Sitesでのビルドとデプロイが別途必要です。GitHub Pages版は `main` へのpushで自動更新されます。
