# 記録を中心にした「きょう」

2026-10-02。「もちに癒されながら、体調と小さな習慣を記録する」が、最初の画面で伝わる構成に整理。

## 画面の役割

| タブ | 内容 |
| --- | --- |
| きょう | 1行の目標、タップ・なでる・長押しの小さなもち、気分／体重／ウォーキング／メモの一体化した記録一覧、習慣、控えめな「今日は休む」 |
| ふりかえり | 今週できたこと（あしあと・週のペース含む）、体重、ウォーキング、直近メモ、直近の記録の順 |
| もち | お部屋のもちと触れ合いの道具、プロフィール・思い出、お話、おさんぽ物語・タイマー、ひと休み・遊び・音、模様がえ、贈りもの |
| ごほうび | 星、お部屋・衣装の解放と試着、希望の衣装、特別なもち |

「今日は軽め」「提案をお休み」「小さな一歩」「週のペース」「今日はここまで」は「もち」の折りたたみ欄から引き続き利用できる。

## 入力と保存

- 気分を押すと3択と保存ボタンだけを表示。詳しい言葉・タグは必要なときだけ展開。
- 体重・ウォーキングはそれぞれ専用のスクロール入力。メモはメモだけのフォーム。
- 各フォームは最新の保存済み記録に対象項目だけを重ね、ほかの値を保つ。
- 前回の体重は「今日は未記録」と明示。今日の値がある場合は前回の日付と増減を表示。
- 習慣はチェックで完了。習慣名を押すと「まだ」「少しできた」「できた」を選択。ほかの習慣を保つ。
- 休むと入力を閉じるが、記録と習慣は保持。「記録を開く」で休んだまま入力できる。
- 成功時は記録欄の小さな保存表示ともちの返事。星獲得や衣装解放の成功通知を入力欄の上に重ねない。保存失敗時の再試行と入力保持は継続。
- 既存の保存キー、データ形式、健康記録、相棒ごとの記憶、ごほうび条件は変更なし。データ移行と追加のDB変更は不要。
