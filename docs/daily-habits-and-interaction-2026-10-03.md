# 毎日の小さな習慣と「ふれあう」画面

2026-10-03

## 毎日3つの習慣

- からだを動かす・伸ばす・休息・食事・気持ち・五感・暮らし・日課・睡眠・人とのつながり・楽しみ・自分へのやさしさの12分野、各15案、計180案。
- 日付からランダムな組み合わせを選ぶ。同日に再表示しても同じ3つ。異なる分野を選び、ひとつの種類に偏らないようにする。
- 初めて表示するときに `Entry.habitNames` へ3つの名前を保存。後日の候補追加や古いクライアントからの編集でも、その日の保存済み名称を置き換えない。
- 更新前の過去の記録、および今日チェック済み・途中までの記録は、以前の設定の習慣名を引き継ぐ。次の新しい日から毎日の3案を表示する。
- 常に3案を表示。「できるものだけ」という案内を添え、チェックや「少しできた」の操作は従来どおり利用できる。
- 表示の保存だけでは体重・気分・歩いた時間・メモを変更しない。健康記録として数えず、星も付与しない。
- 履歴の編集フォームではその日に保存した名前を表示。書き出したJSONにも名前が残る。

## ふれあう画面

- メニューの「もち」を「ふれあう」へ変更。
- お部屋内の画像と吹き出しを横並びにし、高さを抑える。なでる・ぎゅっと・ブラシ・おやつ・おもちゃはすぐ見える位置に残す。
- 追加の表情操作・ひと休み画面などは「もっとふれあう」、表情一覧と会えた日の数は「表情と、これまでのあしあと」にまとめる。
- 「もちとの時間」の6つの入口を1列の大きなボタンにする。それぞれにできることの説明を表示。各画面の既存機能、贈りものの未受取表示を保持する。
- 「きょうの過ごし方」のカードと、目標・設定画面の「もちと過ごすペース」を非表示にする。既存の保存データは保持し、「きょう」の休む・再開は引き続き使える。

## 保存先

GitHub Pages版は既存の `mochi-days:v1` を引き継ぐ。追加の設定は不要。

Sites版のD1には `entries.habit_names` を追加。別途Sites版を更新するときは `drizzle/0005_daily_habit_names.sql` を適用してからアプリをデプロイする。今回の公開先はGitHub Pages。
