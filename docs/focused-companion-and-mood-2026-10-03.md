# 気分の保存・もちとの時間の整理（2026-10-03）

## 気分が未記録に見える問題

未選択の状態で画面を開くと、最初の隠れたラジオボタンにフォーカスが当たり、その親の顔に橙色の枠が表示されていました。実際には気分は `null` のままでも保存でき、選択済みに見える画面と「きょうの記録」の未記録表示が食い違いました。

気分は顔のボタン自体で選択します。選択済みは背景・枠・チェックで表示し、キーボードのフォーカスは別の点線にしました。専用画面では `null` の保存を止めます。元気の値 `0` も記録済みとして扱い、3種類すべて保存・表示・再読込を確認しました。保存時は最新の同日記録に気分だけを反映する既存の処理を保っています。

## 6つの専用画面

各画面内に並んでいた共通の6項目メニューを外し、押した入口の内容だけを表示します。

| 入口 | 最初に見えるもの | その場の操作・結果 |
| --- | --- | --- |
| もちのこと・思い出 | もちの写真、性格、ふれあい数、好みの絵 | お手紙をひらく、思い出を眺める |
| もちとお話しする | もちの吹き出し、絵付きの2つの返事 | 返事にチェックがつき、もちの好みに残る |
| おさんぽの物語 | 景色のカード、歩いた分数の地図、絵本 | 景色を選ぶ、物語の返事を選ぶ |
| ひと休み・小さな遊び | 呼吸するもち、開始ボタン、絵付きの遊び | 深呼吸、五感、絵合わせ、かくれんぼ、おてて、庭あそび |
| お部屋を模様がえ | 選択中の部屋のプレビュー、色・家具などの絵 | プレビューを見て選び、画面下のボタンで保存 |
| もちからの贈りもの | 届いた包み、絵入りの宝もの棚 | ひらくと棚に追加、選んだ品をお部屋に飾る |

プロフィールの好み・呼び名、夜のお話、散歩タイマー、過去の物語、音の設定、お気に入りの部屋、別の相棒の思い出は、それぞれの画面の折りたたみへ移しました。贈りものからその品の物語や飾った部屋を見るなど、内容に関係する移動だけを残しています。遊びや棚で選んだ内容は、画面上部へ戻してすぐ見えるようにします。

## 贈りものの保存

既存の `gifts` の受取状態をそのまま使います。花、貝、葉、手紙、毛糸などを絵で区別し、受け取った品が棚に残ります。季節の小箱と3匹それぞれのコレクションも保持します。

部屋に飾る品のIDは、既存の相棒設定JSONの `preferences.room.keepsakeId` に保存します。持っていない品・未受取の品は保存処理で拒否します。部屋には1つ表示し、棚へ戻しても受取済みのコレクションは消えません。既存データと、追加フィールドを送らない旧画面からの部屋更新にも対応します。DBマイグレーションは不要です。
