## 配布方針

今のWebアプリを使い、iPhoneではSafariを使い、まず試用する利用者だけにアクセスを許可する。URLを全世界へ一般公開する必要はない。Sitesの招待先メールとログインに使うアカウントを確認した後、所有者が許可する。URLや招待を送る前に宛先を確認する。

現在の認証はSitesのアクセス制御とChatGPTログイン。GitHub Pagesだけではこのアプリの認証/API/D1は動かない。Cloudflareへ独立移行する場合は、認証とDBの移行を別の作業として扱う。

GitHub Pagesでは、ログインなしで記録を端末のブラウザに保存する版を公開している（2026-09-29）。URLを開くだけで使えるが、記録は端末ごとで共有・同期しない。iPhoneはSafariとホーム画面のアプリで保存場所が別々なので、ホーム画面に追加してから使い始める。

関連: [ALE-60](https://linear.app/alexahealth/issue/ALE-60) 機種確認、[ALE-66](https://linear.app/alexahealth/issue/ALE-66) 配布先・公開タイミング、[ALE-61](https://linear.app/alexahealth/issue/ALE-61) スマホで開く、[ALE-62](https://linear.app/alexahealth/issue/ALE-62) ホーム画面追加、[ALE-63](https://linear.app/alexahealth/issue/ALE-63) 保存確認、[ALE-64](https://linear.app/alexahealth/issue/ALE-64) チェックリスト、[ALE-65](https://linear.app/alexahealth/issue/ALE-65) フィードバック。

## 一緒に試す順番

1. 対象はiPhone。モデル、iOS、ブラウザ、ログインするアカウントを控える。パスワードは共有しない。
2. 配布済みのアプリURLをSafari/Chromeで開き、本人がログインする。
3. 初回の相棒選択で犬・猫・ペンギンを切り替え、名前を入力して始める。
4. `/install` の案内に沿ってホーム画面に追加する。
5. ブラウザを閉じ、ホーム画面のアイコンから開き直す。再ログインが必要なら同じアカウントを使う。
6. 下の項目を確認し、困った点をALE-65から課題として記録する。

## 実機チェックリスト

- [ ] 未招待のアカウントでは記録にアクセスできない。
- [ ] 招待されたアカウントでログインできる。
- [ ] 3匹の画像が欠けずに表示され、選んだ相棒と名前が保存される。
- [ ] なでる・表情ボタン・気分入力・習慣達成で反応する。
- [ ] 体重を入力しなくても使える。日本語入力と小数の数字入力ができる。
- [ ] 記録後の再読み込みで、今日の記録と星が残る。
- [ ] 同じ習慣を外して付け直しても星は増えない。
- [ ] 5個でバンダナが解放される。未解放の衣装は着られない。
- [ ] 着替えた後、再起動しても衣装が残る。
- [ ] 設定で種類を変えても、記録・星・衣装の解放状況が残る。
- [ ] ホーム画面から起動でき、上下の安全領域とキーボードでボタンが隠れない。
- [ ] 設定・記録のダイアログがスクロールでき、閉じる操作ができる。
- [ ] 回線を切って保存したとき、成功と誤表示しない。再接続後に保存できる。
- [ ] ログアウトして入り直しても、自分の記録を読み込める。

Sites版の記録の保存先は端末のローカルストレージではなく、本人のアカウントに紐づくサーバーです。オフライン保存は未対応。ホーム画面のアイコン削除はアカウントの記録削除ではありません。

### GitHub Pages版で確かめること

- [ ] https://alexahelth.github.io/mochi-days/ を開くと、ログインなしで相棒選びが表示される。
- [ ] Safariで開くと、ホーム画面に先に追加する案内が相棒選びの画面に出る。
- [ ] ホーム画面に追加して開き直しても、相棒・名前・記録・星・衣装が残る。
- [ ] 機内モードでも、開いている画面で記録を保存できる。
- [ ] 設定から自分の記録をJSONで書き出せる。

GitHub Pages版は記録を端末のブラウザにだけ保存します。Webサイトデータの消去やホーム画面のアプリの削除で、記録も消えることがあります。

## 今回追加した確認（2026-09-27）

- [ ] 自由メモだけを保存し、ふりかえりから読み返せる。
- [ ] 日本語の改行・絵文字を含むメモが再起動後も残る。
- [ ] 通信を切って保存すると失敗が分かり、接続後に同じ入力を再保存できる。
- [ ] 通信が遅くても保存中のまま止まらず、保存結果不明を表示する。
- [ ] 設定から自分の記録をJSONで書き出し、iPhoneのファイルに保存できる。
- [ ] 「気づいたことをメモ」で文章をコピーできる。コピー不可なら文章を選択して手動コピーできる。
- [ ] 報告文に体重・自由メモ・メールが自動で入らない。

未送信の入力はページを閉じる前に再保存する。機内モードでアプリを閉じた場合の下書き復元は未対応。
